# Học Java

Repository lưu bài tập, ví dụ và ghi chú trong quá trình học Java.

## Gợi ý sắp xếp

- `basics/` - cú pháp và khái niệm cơ bản
- `exercises/` - bài tập thực hành
- `projects/` - dự án nhỏ
- `notes/` - ghi chú

## Chạy một file Java

```powershell
javac HelloWorld.java
java HelloWorld
```

Các file `.class` được tạo khi biên dịch sẽ không được Git theo dõi.
